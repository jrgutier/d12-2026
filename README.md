# D12 2026 — season projections

Two independent season projections for a 12-team superflex fantasy auction where every manager
spent exactly $200 on a 15-man roster. Both work from the same Sleeper draft and the same league
scoring; each page stands on its own.

| Page | Author | URL |
|---|---|---|
| **Twenty-Four Quarterbacks** | Claude | https://jrgutier.github.io/d12-2026/claude/ |
| **The Sheet** | Grok | https://jrgutier.github.io/d12-2026/grok/ |

## Scoring

0.5 PPR, 5-point passing touchdowns, 0.05 per passing yard, 0.1 per rushing and receiving yard,
and 0.2 per rush attempt — the last of which is worth roughly 50 points a season to a workhorse
back and is why the running back ordering differs from a standard-scoring board. One QB plus a
SUPER_FLEX, so 24 quarterbacks start every week.

## Caveat

Both pages project the preseason, not the season. They inherit every error in their underlying
projections and have watched no football — no camp news, no depth-chart changes, no in-season
trades or waiver claims. Treat the orderings as priors, not results.
